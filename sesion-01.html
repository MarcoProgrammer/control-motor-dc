01 LEYES FÍSICAS Y ECUACIONES DIFERENCIALES

Modelado Físico del Motor DC

Γ ECUACIONES ACOPLADAS DEL SISTEMA

El comportamiento dinámico se divide en el circuito eléctrico de armadura y la mecánica rotacional de la carga:

$$V_a(t) = R_a i_a(t) + L_a \frac{d i_a(t)}{d t} + e_b(t), \quad e_b(t) = K_e \omega(t)$$ $$T_m(t) = K_t i_a(t) = J_m \frac{d \omega(t)}{d t} + B_m \omega(t) + T_L(t)$$
PARÁMETROS ELÉCTRICOS
  • $R_a$: Resistencia de armadura ($\Omega$).
  • $L_a$: Inductancia de armadura ($H$).
  • $K_e$: Constante contraelectromotriz ($V \cdot s/rad$).
PARÁMETROS MECÁNICOS
  • $J_m$: Inercia del rotor y carga ($kg \cdot m^2$).
  • $B_m$: Coeficiente de fricción viscosa ($N \cdot m \cdot s/rad$).
  • $K_t$: Constante de torque ($N \cdot m / A$).

02 REPRESENTACIÓN EN ESPACIO DE ESTADOS CONTINUO

Formulación $\dot{x}(t) = A x(t) + B u(t)$

Γ SELECCIÓN DE LAS VARIABLES DE ESTADO

Definiendo el vector de estados $x(t) = [\omega(t), \, i_a(t)]^T$ y la entrada de control $u(t) = V_a(t)$:

$$\begin{bmatrix} \dot{\omega}(t) \\ \dot{i_a}(t) \end{bmatrix} = \begin{bmatrix} -\frac{B_m}{J_m} & \frac{K_t}{J_m} \\ -\frac{K_e}{L_a} & -\frac{R_a}{L_a} \end{bmatrix} \begin{bmatrix} \omega(t) \\ i_a(t) \end{bmatrix} + \begin{bmatrix} 0 \\ \frac{1}{L_a} \end{bmatrix} V_a(t)$$ $$y(t) = \begin{bmatrix} 1 & 0 \end{bmatrix} \begin{bmatrix} \omega(t) \\ i_a(t) \end{bmatrix}$$
PROPIEDADES DEL SISTEMA MATRICIAL

Los autovalores de la matriz $A$ determinan los polos del sistema en el plano s: $\det(sI - A) = 0$.

03 DISCRETIZACIÓN DE ESTADOS

Formulación Discreta $x(k+1) = \Phi x(k) + \Gamma u(k)$

Γ MÉTODO ZOH (ZERO-ORDER HOLD)

Para su procesamiento en el ESP32 a un tiempo de muestreo $T_s$, se obtiene la solución exacta:

$$\Phi = e^{A T_s} = \mathcal{L}^{-1}\left\{ (sI - A)^{-1} \right\}_{t = T_s}$$ $$\Gamma = \left( \int_{0}^{T_s} e^{A \tau} d\tau \right) B = A^{-1}(\Phi - I)B$$
APROXIMACIÓN DE EULER (PARA EJECUCIÓN RÁPIDA)

Cuando $T_s \ll \tau_{mínima}$, podemos aproximar en código:

$$\Phi \approx I + A T_s, \quad \Gamma \approx B T_s$$

Clase `MotorModel` para Simulación en Hardware

☐ ESTIMADOR EN TIEMPO REAL

Permite simular el comportamiento del motor dentro del propio ESP32 (Hardware-in-the-Loop) sin necesidad de conectar el motor físico.

class ModeloMotorDC { private: float w = 0.0f, i = 0.0f; float Ra = 2.0f, La = 0.05f, Ke = 0.1f, Kt = 0.1f, Jm = 0.02f, Bm = 0.01f; public: void update(float Va, float Ts) { float dw = (Kt * i - Bm * w) / Jm; float di = (Va - Ra * i - Ke * w) / La; w += dw * Ts; i += di * Ts; } float getSpeed() const { return w; } float getCurrent() const { return i; } };
