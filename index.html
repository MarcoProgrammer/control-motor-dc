01 MODELADO MATEMÁTICO

Discretización de la Planta electromecánica

Γ DEFINICIÓN MATEMÁTICA DE LA PLANTA

La dinámica de un motor DC comandado por voltaje armadura $V_a(t)$ viene dada por las ecuaciones diferenciales acopladas:

$$V_a(t) = R_a i_a(t) + L_a \frac{di_a(t)}{dt} + K_e \omega(t)$$ $$J_m \frac{d\omega(t)}{dt} = K_t i_a(t) - B_m \omega(t) - T_L(t)$$
☐ DISCRETIZACIÓN POR EULER HACIA ADELANTE

Para su implementación en el microcontrolador (ESP32) a un periodo de muestreo $T_s$:

$$i_a(k+1) = \left(1 - \frac{R_a T_s}{L_a}\right) i_a(k) + \frac{T_s}{L_a}\left(V_a(k) - K_e \omega(k)\right)$$ $$\omega(k+1) = \left(1 - \frac{B_m T_s}{J_m}\right) \omega(k) + \frac{T_s K_t}{J_m} i_a(k)$$
EN LA PRÁCTICA (ETAPA DE POTENCIA)

El voltaje aplicado $V_a(k)$ proviene de un Puente H con excitación simétrica o asimétrica. En control discreto estricto, la señal de control $u(k) = V_a(k)$ toma valores dentro del conjunto finito de estados de conmutación:

$$S \in \{ +V_{cc}, \, 0\,\text{V}, \, -V_{cc} \}$$

02 TÉCNICAS CLÁSICAS

Control Todo/Nada (ON-OFF) vs PID Discreto

CONTROL ON-OFF CON HISTÉRESIS

Commuta la etapa de potencia al límite. Si el error $e(k) = \omega_{ref} - \omega(k)$ supera la banda de histéresis $\Delta$:

$$V_a(k) = \begin{cases} +V_{cc} & \text{si } e(k) > \Delta \\ -V_{cc} & \text{si } e(k) < -\Delta \\ 0 & \text{en otro caso} \end{cases}$$

Desventaja: Provoca rizado alto (chattering) y desgaste térmico/mecánico acelerado.

PID DISCRETO (ALGORITMO DE VELOCIDAD)

Calcula la variación del esfuerzo de control $\Delta u(k)$ para evitar la saturación del término integral (windup):

$$\Delta u(k) = q_0 e(k) + q_1 e(k-1) + q_2 e(k-2)$$ $$u(k) = \text{sat}\left( u(k-1) + \Delta u(k), \pm V_{cc} \right)$$

Donde los coeficientes $q_0, q_1, q_2$ dependen de $K_p, K_i, K_d$ y $T_s$.

Γ CRITERIO DE INGENIERÍA

El control ON-OFF se limita a sistemas con gran inercia donde la frecuencia de conmutación natural sea baja. Para servoaccionamientos o motores DC de rápida respuesta, la modulación PWM gobernada por PID o MPC es indispensable.

03 CONTROL PREDICTIVO

Finite Control Set Model Predictive Control (FCS-MPC)

Γ FUNDAMENTO DEL FCS-MPC

FCS-MPC no utiliza modulador PWM. En su lugar, utiliza el modelo matemático de la planta para predecir el comportamiento del sistema en el instante $k+1$ para cada uno de los posibles estados de conmutación del Puente H ($S_1 = +V_{cc}$, $S_2 = 0\text{V}$, $S_3 = -V_{cc}$).

FUNCIÓN DE COSTO $J$

Evalúa el criterio de desempeño a optimizar en cada periodo de muestreo:

$$J_i = \left\vert{} \omega_{ref} - \omega_i(k+1) \right\vert{} + \lambda \cdot \left\vert{} i_a^{max} - i_{a,i}(k+1) \right\vert{}$$

El algoritmo selecciona la tensión $V_a(k) \in S$ que minimiza $J$:

$$S_{opt} = \arg \min_{i \in \{1,2,3\}} (J_i)$$
VENTAJAS FRENTE AL PID
  • Respuesta transitoria sumamente rápida (dinámica óptima).
  • Inclusión directa de restricciones no lineales (límites de corriente de armadura, saturación).
  • Sin necesidad de sintonización lineal estricta ($K_p, K_i, K_d$).

> LA HORA DEL CÓDIGO

Implementación FCS-MPC en C++ (ESP32)

ESTRUCTURA DE CÓDIGO POO

Siguiendo las reglas de la clase, el controlador se encapsula sin dependencias globales y se invoca desde una tarea o interrupción de temporizador ($T_s = 1\,\text{ms}$).

CARACTERÍSTICAS
  • Sin llamadas bloqueantes delay().
  • Evaluación finita optimizada mediante directivas inline.
  • Salidas directas a los pines del Puente H.
class FcsMpcMotor { private: float Ra, La, Ke, Kt, Jm, Ts; float Vcc; public: FcsMpcMotor(float r, float l, float ke, float ts) : Ra(r), La(l), Ke(ke), Ts(ts), Vcc(24.0) {} float evaluarEstadoOptimo(float w_ref, float w_act, float i_act) { float S[3] = {Vcc, 0.0f, -Vcc}; float min_J = 1e6; float V_opt = 0.0; for(int k=0; k<3; k++) { float i_pred = (1 - Ra*Ts/La)*i_act + (Ts/La)*(S[k] - Ke*w_act); float w_pred = (1 - 0.01f*Ts)*w_act + (Ts*Kt/0.05f)*i_act; float J = fabs(w_ref - w_pred); // Función de Costo if(J < min_J) { min_J = J; V_opt = S[k]; } } return V_opt; } };
