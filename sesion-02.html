1 / 5SESIÓN 02: CONTROL CLÁSICO

01 ESTRUCTURA PARALELA DEL PID

Ecuación Continua del Controlador PID

Γ ESTRUCTURA PARALELA ESTÁNDAR

La señal de control $u(t)$ responde a la suma ponderada del error presente, acumulado y su tasa de cambio:

$$u(t) = K_p \, e(t) + K_i \int_{0}^{t} e(\tau) d\tau + K_d \frac{d e(t)}{d t}$$ $$e(t) = r(t) - y(t)$$
ACCIÓN PROPORCIONAL ($K_p$)

Reduce el tiempo de subida. Un valor excesivamente alto provoca sobreoscilación e inestabilidad.

ACCIÓN INTEGRAL ($K_i$)

Elimina el error en estado estacionario ($e_{ss} \to 0$). Introduce retraso de fase.

ACCIÓN DERIVATIVA ($K_d$)

Anticipa el comportamiento del error. Agrega amortiguamiento al sistema transitorio.

2 / 5SESIÓN 02: IMPLEMENTACIÓN DIGITAL

02 DISCRETIZACIÓN DE ECUACIONES

Algoritmos Posicional y de Velocidad

ALGORITMO POSICIONAL

Aproxima la integral por suma rectangular y la derivada por diferencia finita:

$$u(k) = K_p e(k) + K_i T_s \sum_{j=0}^{k} e(j) + K_d \frac{e(k) - e(k-1)}{T_s}$$
ALGORITMO DE VELOCIDAD (INCREMENTAL)

Calcula la variación del control $\Delta u(k) = u(k) - u(k-1)$:

$$\Delta u(k) = q_0 e(k) + q_1 e(k-1) + q_2 e(k-2)$$ $$q_0 = K_p + K_i T_s + \frac{K_d}{T_s}, \quad q_1 = -K_p - \frac{2 K_d}{T_s}, \quad q_2 = \frac{K_d}{T_s}$$
MECANISMO ANTI-WINDUP (CLAMPING)

Cuando el actuador (Puente H) se satura ($\pm V_{cc}$), la acumulación integral debe congelarse para evitar el retraso en la recuperación transitoria.

> LA HORA DEL CÓDIGO

Clase `PidController` en C++ con Anti-Windup

☐ IMPLEMENTACIÓN EN ROBUSTA

Incopora límite de salida y prevención de desbordamiento integral mediante filtrado y saturación.

class PidController { private: float Kp, Ki, Kd, minOut, maxOut; float e_prev = 0, integral = 0; public: PidController(float kp, float ki, float kd, float minO, float maxO) : Kp(kp), Ki(ki), Kd(kd), minOut(minO), maxOut(maxO) {} float compute(float setpoint, float measured, float dt) { float error = setpoint - measured; float p_term = Kp * error; integral += error * dt; float i_term = Ki * integral; float d_term = Kd * (error - e_prev) / dt; float output = p_term + i_term + d_term; // Clamping Anti-Windup if (output > maxOut) { output = maxOut; integral -= error * dt; } else if (output < minOut) { output = minOut; integral -= error * dt; } e_prev = error; return output; } };
