01 ESPACIO DE ESTADOS

Representación Matricial del Motor DC

Γ MODELO CONTINUO (MIMO/SISO)

Definiendo el vector de estados $x(t) = [\omega(t), i_a(t)]^T$ y la entrada $u(t) = V_a(t)$, la dinámica del motor se expresa como $\dot{x}(t) = A x(t) + B u(t)$:

$$\begin{bmatrix} \dot{\omega} \\ \dot{i_a} \end{bmatrix} = \begin{bmatrix} -\frac{B_m}{J_m} & \frac{K_t}{J_m} \\ -\frac{K_e}{L_a} & -\frac{R_a}{L_a} \end{bmatrix} \begin{bmatrix} \omega \\ i_a \end{bmatrix} + \begin{bmatrix} 0 \\ \frac{1}{L_a} \end{bmatrix} V_a$$
DISCRETIZACIÓN EXACTA (ZOH)

Para control digital con retentor de orden cero ($T_s$):

$$x(k+1) = \Phi x(k) + \Gamma u(k)$$ $$\Phi = e^{A T_s}, \quad \Gamma = \int_{0}^{T_s} e^{A \tau} d\tau B$$
OBSERVABILIDAD Y CONTROLABILIDAD

La matriz de controlabilidad $\mathcal{C} = [\Gamma \;\; \Phi\Gamma]$ debe ser de rango completo para garantizar que cualquier técnica avanzada (LQR, MPC) sea viable en el ESP32.

02 CONTROL ÓPTIMO

Linear Quadratic Regulator (LQR)

Γ FUNCIÓN DE COSTO CUADRÁTICA

El LQR busca la ley de control óptima $u(k) = -K x(k)$ que minimice el índice de desempeño $J$ en un horizonte infinito, balanceando el error de seguimiento y el gasto energético del puente H:

$$J = \sum_{k=0}^{\infty} \left( x^T(k) Q x(k) + u^T(k) R u(k) \right)$$
MATRICES DE PONDERACIÓN (Q, R)
  • $Q$ (Matriz semi-definida positiva): Penaliza los desvíos de los estados (velocidad y corriente).
  • $R$ (Escalar definido positivo): Penaliza el esfuerzo de control aplicado al actuador.
ECUACIÓN DE RICCATI (DARE)

La ganancia óptima $K$ se calcula resolviendo la Ecuación Algebraica de Riccati en Tiempo Discreto offline:

$$K = (R + \Gamma^T P \Gamma)^{-1} \Gamma^T P \Phi$$

03 INTELIGENCIA COMPUTACIONAL

Controladores Basados en Lógica Difusa

Γ ARQUITECTURA DEL SISTEMA DE INFERENCIA

Cuando el modelo fenomenológico ($R_a, L_a$) es incierto o altamente no lineal (fricción seca de Coulomb), el control difuso codifica la experiencia heurística en reglas IF-THEN evaluadas mediante funciones de pertenencia $\mu(x)$.

1. FUSIFICACIÓN

Las entradas físicas $e(k)$ y $\Delta e(k)$ se mapean a variables lingüísticas: Negativo Grande (NG), Cero (Z), Positivo Pequeño (PP).

2. REGLAS MAMDANI

IF e(k) IS NG AND Δe IS Z
THEN u(k) IS NG

Se evalúan con operadores T-norma (min/prod).

3. DEFUSIFICACIÓN

Se calcula la salida física PWM al Puente H, típicamente por el método del Centro de Gravedad (CoG).

$$u = \frac{\sum \mu(u_i) \cdot u_i}{\sum \mu(u_i)}$$

> LA HORA DEL CÓDIGO

Implementación LQR Matricial en C++

☐ CÁLCULO OFFLINE

El ESP32 no resuelve la ecuación de Riccati en tiempo real. Python/MATLAB calculan la matriz de ganancias $K = [K_1, K_2]$, y el microcontrolador ejecuta un producto punto simple, garantizando tiempos de ejecución en microsegundos ($O(N)$).

// LQR Estático pre-calculado para Ts = 1ms const float K_lqr[2] = {0.842, 0.153}; void isr_control_timer() { // 1. Leer estados físicos (x) float w_act = encoder.getSpeed(); float i_act = ina219.getCurrent(); // 2. Ley de Control LQR: u = -Kx (con tracking) float error_w = w_ref - w_act; float error_i = i_ref - i_act; float u_volt = (K_lqr[0] * error_w) + (K_lqr[1] * error_i); // 3. Saturación anti-windup implícita u_volt = constrain(u_volt, -24.0, 24.0); motor.setVoltage(u_volt); }
